# JustJayDev //alt

A sister site to [JustJayDev.github.io](https://justjaydev.github.io) — same content, completely different **Neon Cyber Terminal** UI.

- Dark glassmorphism + neon glow + grid backdrop + scanlines
- Glitch-typing hero, live ticker, animated stat counters
- Horizontal-scroll game showcase + casual classics marquee
- Full game profiles, RSS-driven devlog

Built with React 18 + TypeScript + Vite + Tailwind + Framer Motion. Live at:
**https://justjaydev.github.io/just-jay-alt/**
